Privacy Policy

Ask Again Later – Studio · Last updated 5 November 2026

Ask Again Later – Studio is a small personal tool used by the creator of the Ask Again Later YouTube channel. It backs up the channel's finished video files to the creator's own Google Drive, uploads the channel's own finished videos to YouTube as private videos, and reads the channel's own YouTube statistics. It is not a public app: it has no user accounts, no sign-up, and it is used only by the channel's owner with their own Google account.

What Google data the app accesses

Google Drive

For backups the app asks Google for one Drive permission: drive.file ("see, edit, create and delete only the specific Google Drive files you use with this app"). Under Google's rules, this permission covers files and folders the app creates, plus files a user explicitly opens or shares with the app. This app has no file picker and never asks you to open or share other files with it.

In practice, the backup tool only works with its own designated backup files and folders. It:

  • creates its backup folders, Ask Again Later › YouTube Shorts › Final Videos, if they don't already exist;
  • uploads finished MP4 video files into Final Videos;
  • looks up its own files and folders (name, file ID, size, checksums and folder) to avoid duplicate uploads and to confirm each upload arrived complete;
  • when its folder layout changes, can move its own backup files into the new folders. This changes only the folder a file is in; the file is not copied, re-uploaded or deleted.

YouTube

For publishing and statistics the app asks Google for two YouTube permissions, granted in a separate sign-in:

  • youtube.upload ("manage your YouTube videos" – upload only): the app uses it only to upload a finished video of the channel that the owner has approved, always as a private video, and to set that private video's thumbnail. It never makes a video public, never schedules one, never edits, replaces or deletes an existing video, and never posts comments.
  • youtube.readonly ("view your YouTube account"): the app reads the signed-in channel's ID and name to confirm it is the Ask Again Later channel before doing anything, reads the status and details of the channel's own uploads (for example whether an upload is private and finished processing), and reads the channel's own YouTube Analytics reports for its published videos – views, engaged views, watch time, average view duration and percentage, likes, comments and shares counts, subscribers gained or lost, traffic-source totals and audience-retention curves. These are aggregate numbers; the app does not receive information about individual viewers.

The app does not request or read your name, email address, contacts or any other Google account data.

How the information is used

Only to store and verify backups of the channel's own videos, to upload the channel's own approved videos as private videos and check that they arrived with the approved settings, and to measure how the channel's own published videos perform so the owner can make better videos. The app does not delete or overwrite files in Google Drive, and it does not delete or change existing YouTube videos.

What is stored, and where

  • Sign-in credentials: after the owner signs in, Google issues an authorisation token. It is stored privately on the computer or development environment that runs the tool, and is never published or put in source code.
  • Backup records: for each uploaded video the tool records the Drive file ID, file name, folder name, file size, a SHA-256 checksum, the backup status and the date. These records are kept in the channel's private production repository on GitHub.
  • Upload records: for each private upload the tool records the YouTube video ID, title, privacy status, a SHA-256 checksum of the uploaded file, the processing status and the date, in the same private repository.
  • Statistics: the channel's own YouTube Analytics figures listed above, with the date range they cover, in the same private repository. They are kept to compare the channel's videos over time.
  • The videos themselves are stored in the owner's Google Drive and on the owner's YouTube channel.

Service providers and sharing

The tool sends video files, backup requests, upload requests and statistics requests only to Google's APIs. It is operated by the owner through Claude Code, an AI coding assistant, so backup and upload metadata (file names, Drive file IDs, YouTube video IDs and status) and the channel's statistics are processed by Claude Code and can appear in the owner's session history with that service. The records are stored in the channel's private GitHub repository. Sign-in credentials are not displayed in that output.

The tool does not sell this data and does not use it for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The app uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy.

How to revoke access or delete data

  • Remove the app's access at any time in your Google Account: myaccount.google.com/connections → select Ask Again Later – Studio → remove its access. Any stored credentials then stop working.
  • Delete the locally stored authentication credentials on the computer or environment that ran the tool.
  • Delete the backed-up videos or folders directly in Google Drive, and the uploaded videos in YouTube Studio.
