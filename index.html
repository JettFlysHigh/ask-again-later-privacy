Privacy Policy

Ask Again Later – Studio · Last updated 2 November 2026

Ask Again Later – Studio is a small personal tool used by the creator of the Ask Again Later YouTube channel. It backs up the channel's finished video files to the creator's own Google Drive. It is not a public app: it has no user accounts, no sign-up, and it is used only by the channel's owner with their own Google account.

What Google data the app accesses

The app asks Google for one permission: drive.file ("see, edit, create and delete only the specific Google Drive files you use with this app"). Under Google's rules, this permission covers files and folders the app creates, plus files a user explicitly opens or shares with the app. This app has no file picker and never asks you to open or share other files with it.

In practice, the backup tool only works with its own designated backup files and folders. It:

  • creates two folders, Ask Again Later and inside it Final Videos;
  • uploads finished MP4 video files into Final Videos;
  • looks up its own files in that folder (name, file ID, size and checksums) to avoid duplicate uploads and to confirm each upload arrived complete.

The app does not request or read your name, email address, contacts or any other Google account data, and it does not use any YouTube permission.

How the information is used

Only to store and verify backups of the channel's own videos. The app does not delete or overwrite files in Google Drive.

What is stored, and where

  • Sign-in credentials: after the owner signs in, Google issues an authorisation token. It is stored privately on the computer or development environment that runs the tool, and is never published or put in source code.
  • Backup records: for each uploaded video the tool records the Drive file ID, file name, folder name, file size, a SHA-256 checksum, the backup status and the date. These records are kept in the channel's private production repository on GitHub.
  • The videos themselves are stored in the owner's Google Drive.

Service providers and sharing

The tool sends video files and backup requests to Google's APIs to perform the backup. It is operated by the owner through Claude Code, an AI coding assistant, so backup metadata (file names, Drive file IDs and backup status) is processed by Claude Code and can appear in the owner's session history with that service. The backup records are stored in the channel's private GitHub repository. Sign-in credentials are not displayed in that output.

The tool does not sell this data and does not use it for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access or delete data

  • Remove the app's access at any time in your Google Account: myaccount.google.com/connections → select Ask Again Later – Studio → remove its access. Any stored credentials then stop working.
  • Delete the locally stored authentication credentials on the computer or environment that ran the tool.
  • Delete the backed-up videos or folders directly in Google Drive.
